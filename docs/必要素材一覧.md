# 必要素材一覧（Chill Night Town）

素材の**規格**・**制作状況**・**差し替え手順**をまとめる。読む人によって必要な章が違うため、3つに分けている。

| 章 | 内容 | 主に読む人 |
| :--- | :--- | :--- |
| **A. 素材の規格** | 素材を作るときに守ること（枚数・解像度・命名・形式） | 素材を作る人 |
| **B. 制作状況** | 今どこまで揃っているか。何が仮素材・未制作か | 全員 |
| **C. 差し替え手順** | 届いた素材をコードのどこへ入れるか | 実装する人 |

**構図・建物・何を育てるかは決めていない**（[街デザイン](街デザイン/README.md) 参照）。A章は「守らないと表示が壊れるもの」だけを書いており、絵の内容は指定しない。

状態の凡例（B章で使う）:

- ✅ **完成**（差し替え不要）
- 🟡 **仮素材あり**（差し替え前提）
- 🔵 **暫定実装**（コード描画・絵文字。素材が無くても成立しているが、最終的には差し替えたい）
- 🔴 **未制作**

# A. 素材の規格

## A-1. 街の背景（静止画）

背景はアプリの主役であり、**表示・スワイプ探索・横画面がすべてこの画像の実寸に依存する**。以下は絵の内容ではなく、破ると表示が壊れる条件。

- **1街につき 時間帯5種 × レベル5段階 ＝ 25枚**。時間帯の定義と時刻の境界は [背景_季節×時間帯スケジュール](背景_季節×時間帯スケジュール.md) にある（`latenight` は 23:00〜日の出前。`sunrise` / `sunset` は「夕方」ではなく空が焼けている1時間前後の帯）
- **25枚は解像度も構図も完全に揃える**。[`src/components/pannable-backdrop.tsx`](../src/components/pannable-backdrop.tsx) が画像の実寸から表示倍率とスワイプの可動域を計算するため、枚数の中で寸法が違うと**レベルが上がった瞬間・時間帯が変わった瞬間に街の見える位置と動かせる幅が変わる**
- **既存素材の実寸は 1672×941（16:9）**。nightTown の25枚がこの寸法で揃っている
- **空の色は画像に焼き込む**。アプリ側で時刻に応じた色を重ねる仕組みは**無い**。sunrise / day / sunset / night / latenight はそれぞれ完成した空として描く
- **雨・雪・霧などの天気は背景に描き込まない**。天気11種は別レイヤーとして背景の上に重なる（A-3）。背景に描くと、別の天気を選んだ夜にも降り続けることになる
- **レベルは一度上がったら下がらない**（要件6.1）。Lv1〜5 は前段を含んで積み上がる関係で、**レベルが上がって何かが消えることはない**
- **横画面では上下が切れる**。横向き表示は `cover` 固定（[`landscape-home.tsx`](../src/components/landscape-home.tsx) の `CONTENT_FIT`）のため、16:9 の絵を縦長比の端末に横向きで敷くと上下が欠ける。**主役を上下端に置かない**
- **置き場所・命名**: `assets/home/<town>/<timeOfDay>/png/<town>_<timeOfDay>_lv<N>.png`。プログラムが日時とレベルから自動で読むため、命名は厳格に守る
- **街コード**は `nightTown` / `castleTown` / `starHill` / `snowTown`。DBの `town.code`・ディレクトリ名・コードのキーを兼ねる

> **形式は PNG のまま。圧縮はしない**（決定済み）。1枚あたり 2.4〜2.8MB で、25枚×4街＝100枚なら約250MB になるが、背景は画面全体を占める主役であり、圧縮による劣化（空のグラデーションの帯・夜景の暗部のノイズ）が最も出やすい素材のため、画質を優先する。ストアで配信する段になって容量が問題になれば、そのとき改めて判断する。

## A-2. 街の背景（ループ動画・MP4）

灯りの揺らぎ・流れ星など、ゆるやかに動く背景。**素材があるものだけ動画**になり、無ければ静止画のまま表示される。

- **置き場所**: `assets/home/<town>/<timeOfDay>/mp4/<town>_<timeOfDay>_lv<N>.mp4`（静止画と同じ命名。時間帯フォルダの中で `png/` と `mp4/` に分ける）
- **解像度・構図は対応する静止画と同一**にする（揃っていないとパンの可動域が静止画と変わる）
- **対応する静止画は必ず残す**。読み込み中の下敷き・設定オフ時・街の一覧のサムネイルに使う
- **音声トラックを含めない**（無音）。動画側の音は一切使わない
- 尺 8〜15秒。**先頭と末尾のフレームを一致させ**、継ぎ目が分からないループにする
- 形式: H.264 / yuv420p / MP4、`-movflags +faststart`
- 1本あたり 2〜5MB を目安（25本×4街をすべて動画にすると容量が大きいため、動かす価値のある背景から順に用意する）
- **1つの枠に複数パターンを置ける**（構図は同じで、流れ星などの**動きだけ**が違うもの）。末尾に連番を付ける: `<town>_<timeOfDay>_lv<N>_1.mp4` / `_2.mp4`。どれを流すかは**学習日ごとに決まる**（同じ夜のあいだは切り替わらない）
  - **静止画は枠に1枚のまま**でよい。構図が同じなので、どのパターンの下敷きにも使える。**構図そのものを変えたい場合はパターンにせず、別レベル・別時間帯の素材として扱う**

## A-3. 天気の演出（背景に重ねるレイヤー）

背景（街）とは別の軸で、その学習日に選択された天気に応じて上から重ねる。**天気1種につき1本**で済み、背景の枚数（街×時間帯×レベル）とは掛け算にならない。

- **置き場所**: `assets/home/weather/<name>.mp4`
- **アルファチャンネルは使わない**（H.264 に無いため）。**真っ黒な背景に、雨など見せたいものだけを明るく描く**。描画側で `mixBlendMode: "screen"` を掛けて黒を抜く
- そのため**暗くする表現は作れない**（豪雨で街が沈む等）。必要なら半透明の暗い板を別に重ねる
- 濃さはコード側の `opacity` で調整する。強すぎると街の灯り・海・空が雨に埋もれ、弱すぎると選んだことに気づけない
- 尺・形式・無音・ループの継ぎ目は A-2 と同じ。**解像度を揃える必要はない**（画面いっぱいに敷くだけで、スワイプ探索の対象外）
- 街と一緒にスワイプで動かさない（雨はカメラの手前にあるもので、街と一緒に流れると視点がおかしくなる）

## A-4. 音源

- **分類は BGM／環境音／効果音／鐘の音の4種**（各0〜100で音量調整・設定画面に実装済み）
- **鐘**（終了演出）は街ごとに音色を変えてよいが、**やわらかい余韻という気分は全街共通**にする（詳細は `assets/audio/bell/README.md`）
- **休憩提案の通知音**は、それとなく柔らかく「休憩の時間」と分かる音にする。**急かすアラームにしない**。鐘とは別の音
- **ポモドーロの切替音・UI操作音**は控えめに。学習中に鳴るため、驚かせない
- 環境音は**夜の天気に応じて自動再生**される。天気11種（星空/月灯り/満月/闇夜/雲間/雨音/嵐/雪明かり/静寂/霧/花火）に対応する音があると望ましい

## A-5. その他の画像

- **レベルの灯り**（Lv1〜5）: レベルが上がるほど発光が育つ表現。**記号に月は使わない**（月は「夜の天気」が所有・要件3.4）
- **ホームの丸アイコン**: 下地・枠（半透明＋白枠）は時計・Lv・バッテリーと同じデザイン言語なので揃える
- **住人（NPC）の立ち絵は作らない**。住人は文面と紹介文だけで表す

# C. 差し替え手順

未登録・未制作の素材は「鳴らす／表示する経路はあるが、無音・フォールバック」で通るようになっている。届いた素材は下記へ登録するだけで有効になる。

| 素材 | 差し替え先 |
| :--- | :--- |
| 街の背景（静止画） | [`src/constants/townArt.ts`](../src/constants/townArt.ts)。RN の `require` は動的にできないため、街コード×時間帯×レベルで静的登録する。時間帯差分は各街に `day` / `sunrise` / `sunset` / `latenight` キーを足すだけで反映され、未登録の時間帯は `night` へフォールバックする |
| 街の背景（動画） | [`src/constants/townVideo.ts`](../src/constants/townVideo.ts) に `require` と**解像度（幅・高さ）**を書く。MP4 は静止画と違い実寸を取得できず、スワイプ探索の可動域計算に解像度が要るため。パターンの選び方は [`src/lib/video-variant.ts`](../src/lib/video-variant.ts) |
| 天気の演出 | [`src/constants/weatherEffect.ts`](../src/constants/weatherEffect.ts)（`night_weather.code` をキーに登録） |
| 音源すべて | [`src/constants/audioAssets.ts`](../src/constants/audioAssets.ts)（BGM・環境音は `ambient_sound.code` をキー、効果音・鐘は用途名をキー）。街ごとの鐘は `assets/audio/bell/<townCode>/<townCode>_bell.mp3` に置き `TOWN_BELL` に1行足す |
| 環境音と天気の対応 | [`src/lib/ambient-select.ts`](../src/lib/ambient-select.ts) |
| レベルの灯り | [`src/components/level-badge.tsx`](../src/components/level-badge.tsx)（差し替え時、発光調整の定数 `CORE_OPACITY_*` / `HALO_*` / `SHADOW_*` は不要になる可能性が高い） |
| ホームの丸アイコン | [`src/components/round-icon-button.tsx`](../src/components/round-icon-button.tsx)（`name`＝Ionicons名 を画像ソース受け取りへ改修。呼び出し側は `src/app/index.tsx` の `SideIcons` / `ImmersiveButton`） |
| 感情・天気のアイコン | マスタに画像パス列を足すか、コード側でコード値→画像のマップを持つ（実装時に判断） |
| 住人の名前・紹介文・文面 | [NPCセリフ集](NPCセリフ集.md) を直して `npm run npc:seed`（`db/seed_npc.sql` が再生成される。SQLは編集しない） |
| 街の名称・説明 | `db/chill_night_town_シードデータ.sql` の `town` INSERT |
| アプリアイコン | `assets/images/icon.png` / `splash-icon.png` / `favicon.png` / `android-icon-*`（`app.json` の参照を確認） |

## 共通の注意

- **音の分類は確定済み**: マスタ `ambient_sound` の `sound_type` は `bgm` / `ambient` のまま拡張せず、**効果音・鐘はアプリ側の定数マップ（`audioAssets.ts`）で持つ**。環境音の `ambient_sound` 行はデータモデル整備（将来の個別選択）として未追加＝A案（再生には不要）
- 音量0の音は再生処理自体を行わない
- **DBスキーマに関わる素材**（街名・街コードなど）は、CLAUDE.md の方針に従い**先にテーブル定義書・シードSQLを更新してから**コードを変える
- **開発用テストボタン**（`__DEV__` 限定）は素材と無関係だが、リリース前に撤去する（[開発用テストボタン](開発用テストボタン.md) の撤去チェックリスト）
