# 必要素材一覧（Chill Night Town）

このアプリに必要な素材（絵・音）について、**作るときの決まりごと**・**今どこまで揃っているか**・**届いた素材をどう組み込むか**をまとめたものです。

読む人によって必要な章が違うので、3つに分けています。

| 章 | 内容 | 読む人 |
| :--- | :--- | :--- |
| **[A. 素材の規格](#a-素材の規格)** | 素材を作るときに守ること | **素材を作る人**（ここだけ読めばOK） |
| **[B. 制作状況](#b-制作状況)** | 今どこまで揃っているか | 全員 |
| **[C. 組み込み手順](#c-組み込み手順)** | 届いた素材をコードのどこへ入れるか | 実装する人（素材を作る人は読まなくて大丈夫です） |

**絵の内容（構図・建物・色）は指定していません。**自由に描いてください。A章に書いてあるのは「守らないとアプリの表示が壊れてしまうこと」だけです。→ [街デザイン](街デザイン/README.md)

# A. 素材の規格

## A-1. 街の背景（静止画）— いちばん大事な素材

アプリを開くと最初に見えて、ずっと画面を占めている絵です。

### 何枚必要か

**1つの街につき25枚**です。

**5つの時間帯 × 5段階のレベル = 25枚**

時間帯というのは、現実の時刻に合わせて背景が切り替わる仕組みのことです。夜11時にアプリを開けば深夜の空が、昼に開けば昼の空が出ます。

| 時間帯 | どんな空か | だいたいの時刻 |
| :--- | :--- | :--- |
| **深夜**（latenight） | 最も深い夜。**アプリが一番よく使われる時間** | 23:00 〜 日の出前 |
| **夜**（night） | 暗くなってから深夜まで。**ここもよく使われます** | 17:10〜19:30 ごろから 23:00 |
| **日没**（sunset） | 空が赤く焼けている短い時間。「夕方」ではなく**日が沈む前後の1時間ほど** | 16:00〜19:30 ごろ |
| **昼**（day） | 明るい時間 | 朝 〜 夕方 |
| **日の出**（sunrise） | 空が白み始めて、太陽が昇りきるまでの1時間ほど | 4:10〜7:10 ごろ |

※時刻の幅があるのは、**季節によって境目が動く**ためです（夏は19時でもまだ明るく、冬は17時にはもう暗い）。正確な境界は [背景_季節×時間帯スケジュール](背景_季節×時間帯スケジュール.md) にあります。絵を描くうえでは「季節ごとに描き分ける必要はない」とだけ分かっていれば大丈夫です。**1枚の絵が春夏秋冬すべてで使われます。**

> **優先順位**: このアプリは夜（18:00〜翌5:00）に使うものなので、**「夜」と「深夜」の10枚がいちばん重要**です。25枚を一度に揃えるのが大変なら、夜 → 深夜 → 日没 → 日の出 → 昼 の順に作ってもらえると助かります。

### レベルとは

勉強を続けると街が Lv1 → Lv5 と育っていきます。**レベルは絶対に下がりません**。

つまり **Lv1〜Lv5 は「増えていく」5枚**になります。Lv2 は Lv1 に何かが足された絵、Lv3 はさらに足された絵……という関係です。

**レベルが上がって何かが消えるのはNG**です。たとえば「Lv3の小屋がLv4で建て替えられて無くなる」といった変化は、ユーザーには育ったのではなく失われたように見えてしまいます。

### サイズ

- **1672 × 941 ピクセル（16:9）**。すでに完成している「夜の街」の25枚がこのサイズです
- **形式は PNG**。圧縮はしません（夜空のグラデーションや暗い部分は、圧縮すると縞模様やザラつきが出やすいため）
- **25枚すべて、まったく同じサイズにしてください**

> **なぜサイズを揃える必要があるのか**: アプリは画像の縦横のピクセル数を読み取って、「画面にどう収めるか」「指でスワイプしたときどれだけ動かせるか」を計算しています。25枚の中でサイズが違う絵が混ざっていると、**レベルが上がった瞬間や時間帯が切り替わった瞬間に、街の見える位置がガタッとずれます。**

### 同じ街の25枚は、同じ構図で

カメラの位置・角度・街との距離を、**25枚すべてで完全に揃えてください**。

変わるのは「空の色（時間帯）」と「街に増えていくもの（レベル）」の2つだけです。時間帯が変わったときもレベルが上がったときも、**画面はその場でパッと切り替わります**。構図がずれていると、街が動いたように見えてしまいます。

### 描き込まないでほしいもの

**雨・雪・霧・花火などの天気は、背景に描かないでください。**

このアプリには「今夜の天気」を選ぶ機能があり、選ばれた天気は**アプリが背景の上に重ねて表示します**（全11種）。背景に描き込んでしまうと、晴れの夜を選んでも雨が降り続けることになります。

**空の色は描き込んでください。**こちらは逆です。時間帯ごとの空の色をアプリ側で乗せる仕組みは**ありません**。日の出・昼・日没・夜・深夜の5枚は、それぞれ**完成した空**として描いてください。

### 横向きにしたときのこと

このアプリは端末を横に倒すと、街を眺めるモード（置き時計のような使い方）になります。このとき**画像の上下が切れます**。

**大事なものを画面の上端・下端ギリギリに置かないでください。**真ん中あたりに主役が来るようにしてもらえると安全です。

### ファイル名と置き場所

プログラムが自動で読み込むため、**名前は厳密に**お願いします。

```
assets/home/<街の英字名>/<時間帯>/png/<街の英字名>_<時間帯>_lv<数字>.png
```

実例（夜の街・夜・Lv3 の場合）:

```
assets/home/nightTown/night/png/nightTown_night_lv3.png
```

使う英字名はこちらです。

| 街 | 英字名 |
| :--- | :--- |
| 夜の街 | `nightTown` |
| 夜桜の城下町 | `castleTown` |
| 星見の丘 | `starHill` |
| 雪国 | `snowTown` |

| 時間帯 | 英字名 |
| :--- | :--- |
| 日の出 | `sunrise` |
| 昼 | `day` |
| 日没 | `sunset` |
| 夜 | `night` |
| 深夜 | `latenight` |

- [ ] 全部 1672 × 941 ピクセルの PNG

## A-2. 街の背景（動く版・MP4）

灯りがゆらいだり、流れ星が横切ったり、**ゆるやかに動く背景**です。

これは**任意**です。動画が用意された絵だけが動き、無ければ静止画のまま表示されます（ユーザーが設定でオフにすることもできます）。

- **必ず、対応する静止画とセットで**作ってください。静止画は読み込み中の下敷きや、設定でオフにしたときに使うので、動画だけでは成立しません
- **サイズも構図も、対応する静止画とまったく同じ**にしてください
- **音は入れないでください**（無音）。動画の音声は一切使いません
- **長さ 8〜15秒**。**先頭と末尾のコマをぴったり一致させて**、繰り返し再生しても継ぎ目が分からないようにしてください
- 形式: H.264 / yuv420p / MP4、`-movflags +faststart`
- 1本あたり 2〜5MB を目安に（全部を動画にすると容量が大きくなるので、動かす価値のあるものから）
- 置き場所: `assets/home/<街>/<時間帯>/mp4/<街>_<時間帯>_lv<数字>.mp4`（静止画と同じ名前で、フォルダだけ `png` → `mp4`）

**同じ枠に複数パターンを置くこともできます。**構図は同じで、流れ星の流れ方などの**動きだけ**が違うものです。この場合はファイル名の末尾に連番を付けます（`..._lv3_1.mp4` / `..._lv3_2.mp4`）。どれが流れるかは**その夜ごとに決まり**、同じ夜のあいだは切り替わりません。

※構図そのものを変えたい場合は、パターンではなく別のレベル・別の時間帯の素材として扱ってください（静止画とずれてしまうため）。

## A-3. 天気の演出（背景に重ねるもの）

「今夜の天気」で選ばれたときに、背景の上に重ねて表示される動画です。**天気1種につき1本**で済みます（街ごとに作る必要はありません）。

対象は11種: 星空 / 月灯り / 満月 / 闇夜 / 雲間 / 雨音 / 嵐 / 雪明かり / 静寂 / 霧 / 花火

- **背景を真っ黒にして、見せたいもの（雨粒など）だけを明るく描いてください。**透過（アルファチャンネル）は使えないため、アプリ側で「黒い部分を透明にする」処理をしています
- そのため、**暗くする表現は作れません**（豪雨で街が沈むような表現）。必要なら別途相談してください
- 長さ・形式・無音・ループの継ぎ目は A-2 と同じ
- **サイズは揃えなくて大丈夫です**（画面いっぱいに敷くだけなので）
- 置き場所: `assets/home/weather/<名前>.mp4`

濃さはアプリ側で調整できます。**濃すぎると街の灯りや空が雨に埋もれ、薄すぎると選んだことに気づけない**ので、調整前提で作っていただいて構いません。

## A-4. 音

深夜に、たいていイヤホンで聴かれます。**驚かせない・急かさない**が全体の方針です。

音は4種類に分かれていて、ユーザーはそれぞれ音量を0〜100で調整できます。

| 種類 | 何の音か |
| :--- | :--- |
| **BGM** | 流しっぱなしの音楽（Lo-Fi など） |
| **環境音** | 雨音・波音など。**選ばれた天気に応じて自動で流れます** |
| **効果音** | ボタン操作音、ポモドーロの休憩の切り替わりなど |
| **鐘の音** | 勉強を終えたときに鳴る、締めくくりの音 |

- **鐘**は街ごとに音色を変えてかまいません（例: 夜の街＝時計台のベル、城下町＝梵鐘）。ただし**やわらかい余韻という気分は全街で共通**にしてください（詳しくは `assets/audio/bell/README.md`）
- **休憩をすすめる通知音**は、それとなく柔らかく「休憩の時間だな」と分かる音に。**アラームのように急かす音にはしないでください。**終了の鐘とは別の音です
- **ポモドーロの切り替わり音・操作音**は控えめに。勉強している最中に鳴るためです
- 環境音は天気11種ぶんあるのが理想ですが、まずは使用頻度の高いものからで大丈夫です

## A-5. そのほかの絵

- **レベルの灯り**（Lv1〜5）: 画面に出る小さな「街のレベル」表示です。レベルが上がるほど光が育つ表現にします。**記号に月は使わないでください**（月は「夜の天気」のほうで使っているため）
- **ホームの丸いアイコン**: カレンダー・設定・おやすみ・鑑賞モードの4つ。下地と枠（半透明＋白い枠）は、時計やバッテリー表示と同じ見た目に揃えてください
- **住人（NPC）の立ち絵は作りません。**住人は文章だけで表現します

# C. 組み込み手順

**実装する人向けです。素材を作る人は読まなくて大丈夫です。**

未登録・未制作の素材は「表示する／鳴らす経路はあるが、無音・フォールバック」で通るようになっている。届いた素材は下記へ登録するだけで有効になる。

| 素材 | 差し替え先 |
| :--- | :--- |
| 街の背景（静止画） | [`src/constants/townArt.ts`](../src/constants/townArt.ts)。RN の `require` は動的にできないため、街コード×時間帯×レベルで静的登録する。時間帯差分は各街に `day` / `sunrise` / `sunset` / `latenight` キーを足すだけで反映され、未登録の時間帯は `night` へフォールバックする |
| 街の背景（動画） | [`src/constants/townVideo.ts`](../src/constants/townVideo.ts) に `require` と**解像度（幅・高さ）**を書く。MP4 は静止画と違い実寸を取得できず、スワイプ探索の可動域計算に解像度が要るため。パターンの選び方は [`src/lib/video-variant.ts`](../src/lib/video-variant.ts) |
| 天気の演出 | [`src/constants/weatherEffect.ts`](../src/constants/weatherEffect.ts)（`night_weather.code` をキーに登録）。濃さは `opacity` で調整。街と一緒にスワイプで動かさない（雨はカメラの手前にあるもので、街と一緒に流れると視点がおかしくなる） |
| 音源すべて | [`src/constants/audioAssets.ts`](../src/constants/audioAssets.ts)（BGM・環境音は `ambient_sound.code` をキー、効果音・鐘は用途名をキー）。街ごとの鐘は `assets/audio/bell/<townCode>/<townCode>_bell.mp3` に置き `TOWN_BELL` に1行足す |
| 環境音と天気の対応 | [`src/lib/ambient-select.ts`](../src/lib/ambient-select.ts) |
| レベルの灯り | [`src/components/level-badge.tsx`](../src/components/level-badge.tsx)（差し替え時、発光調整の定数 `CORE_OPACITY_*` / `HALO_*` / `SHADOW_*` は不要になる可能性が高い） |
| ホームの丸アイコン | [`src/components/round-icon-button.tsx`](../src/components/round-icon-button.tsx)（`name`＝Ionicons名 を画像ソース受け取りへ改修。呼び出し側は `src/app/index.tsx` の `SideIcons` / `ImmersiveButton`） |
| 感情・天気のアイコン | マスタに画像パス列を足すか、コード側でコード値→画像のマップを持つ（実装時に判断） |
| 住人の名前・紹介文・文面 | [NPCセリフ集](NPCセリフ集.md) を直して `npm run npc:seed`（`db/seed_npc.sql` が再生成される。SQLは編集しない） |
| 街の名称・説明 | `db/chill_night_town_シードデータ.sql` の `town` INSERT |
| アプリアイコン | `assets/images/icon.png` / `splash-icon.png` / `favicon.png` / `android-icon-*`（`app.json` の参照を確認） |

## 共通の注意

- **横画面の切れ**: 横向き表示は `cover` 固定（[`landscape-home.tsx`](../src/components/landscape-home.tsx) の `CONTENT_FIT`）。見栄えが悪ければ `"contain"` へ切替可
- **背景の実寸依存**: [`pannable-backdrop.tsx`](../src/components/pannable-backdrop.tsx) が画像の実寸から表示倍率とスワイプの可動域を計算する。A-1で25枚のサイズ統一を求めているのはこのため
- **音の分類は確定済み**: マスタ `ambient_sound` の `sound_type` は `bgm` / `ambient` のまま拡張せず、**効果音・鐘はアプリ側の定数マップ（`audioAssets.ts`）で持つ**。環境音の `ambient_sound` 行はデータモデル整備（将来の個別選択）として未追加＝A案（再生には不要）
- 音量0の音は再生処理自体を行わない
- **DBスキーマに関わる素材**（街名・街コードなど）は、CLAUDE.md の方針に従い**先にテーブル定義書・シードSQLを更新してから**コードを変える
- **開発用テストボタン**（`__DEV__` 限定）は素材と無関係だが、リリース前に撤去する（[開発用テストボタン](開発用テストボタン.md) の撤去チェックリスト）
