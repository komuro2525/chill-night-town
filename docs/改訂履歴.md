# 改訂履歴

本書は設計ドキュメントの**変更経緯と、その判断理由**を1箇所にまとめたものである。
各文書の本文は「今どうなっているか」だけを述べるため、**なぜそう決めたか・なぜそうしなかったか**はここにしか残らない。
仕様を変更するときは、本文の修正とあわせて本書へ1行追加する。

- 番号は各文書ごとの通し番号で、追加順に振る（欠番があってもよい）
- 本書は追記のみとし、過去の行は書き換えない（覆した判断は新しい番号で「〇〇では△△としていたが」と述べる）
- ユースケース設計書の変更は、対応する要件・テーブルの改訂に含めて記す（同書は独立した履歴を持たない）
