# 街デザイン

各街（世界）について、**決まっていること**だけを記録する。値域・制約・処理フローの正は [要件定義書](../要件定義書.md)／[ユースケース設計書](../ユースケース設計書.md)／[テーブル定義書](../テーブル定義書.md) にある。

構図・建物・何を育てるかは**あえて決めない**。素材を作る人が自由に描けるようにするため、ここには街ごとの絵の指定を置かない。素材として守る必要のある規格（枚数・解像度・命名・空の扱いなど）は [必要素材一覧](../必要素材一覧.md) にまとめる。

## 街一覧

| 街コード | 表示名 | コンセプト |
| :--- | :--- | :--- |
| `nightTown` | 夜の街 ※仮 | 高台から海辺の街の灯りを眺める（実装済み・唯一素材が揃っている街） |
| `castleTown` | 夜桜の城下町 ※仮 | 和風。夜桜と灯りが増える街 |
| `starHill` | 星見の丘 | 街の灯りではなく、星空そのものが育っていく場所 |
| `snowTown` | 雪国 ※仮 | 雪景色の中の灯り |

街コードは DB の `town.code`・アセットのディレクトリ名・`src/constants/townArt.ts` のキーを兼ねるため、**変更するとコードとデータの両方に波及する**。

`starHill` だけ `〜Town` で揃えていないのは、「ここは街ではない特別な場所」を型でも示すため。

## 全街に共通する決まり

- **レベルは一度上がったら下がらない**（要件6.1）。Lv1〜5 は前段を含んで積み上がる関係にあり、レベルが上がって**何かが消えることはない**
- **Lv5 到達時に一度だけ特別な演出**を出す。何を出すかは街ごとに決めてよい（現在の案: starHill＝星が弧を描く／castleTown＝花びらが舞う／nightTown＝流れ星が走る／snowTown＝オーロラ）
- **住人（NPC）は街に属する**。人物像・声色・文面の正は [NPCセリフ集](../NPCセリフ集.md) にあり、本フォルダでは扱わない
