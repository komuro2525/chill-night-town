# 街デザイン

## このアプリの「街」とは

Chill Night Town は、夜に勉強する人のためのアプリです。勉強した時間が積み上がると、背景に映っている**街が少しずつ育っていきます**。

コンセプトは「勉強を管理する」ではなく、**「またこの世界に帰ってきたい夜の街」**。だからこの街は、頑張りを測るグラフではなく、**帰ってくる場所**です。

街は全部で4つあり、ユーザーは好きな街をひとつ選んで、そこで夜を過ごします。

## 街は4つ

| 街 | どんな場所か |
| :--- | :--- |
| **夜の街**（仮） | 高台から、海辺の街の灯りを見下ろす。**唯一、絵が完成している街** |
| **夜桜の城下町**（仮） | 和風。夜桜と灯りが増えていく街 |
| **星見の丘** | 街の灯りではなく、**星空そのもの**が育っていく場所 |
| **雪国**（仮） | 雪景色の中の灯り |

※「（仮）」は名前がまだ決まっていないという意味です。絵ができてから決めます。

## 育つ、とは

街には **Lv1〜Lv5 の5段階**があります。ユーザーが勉強を続けると上がっていきます。

大事なルールが1つあります。

> **レベルは一度上がったら、絶対に下がりません。**

サボっても街は元に戻りません。責めない・急かさないというアプリの方針を、この仕様そのもので守っています。

このため、**Lv1〜Lv5 は「増えていく」関係**になります。Lv2 は Lv1 に何かが足された絵、Lv3 は Lv2 にさらに足された絵……という具合です。**レベルが上がって何かが消える・無くなるのはNG**です（例: Lv3にあった小屋がLv4で建て替えられて消える、など）。

Lv5 に到達したときだけ、**一度きりの特別な演出**が出ます。何を出すかは街ごとに自由に決めてかまいません。今のところ、こんな案があります（あくまで案です）。

- 星見の丘 → 星が弧を描く
- 城下町 → 花びらが舞う
- 夜の街 → 流れ星が走る
- 雪国 → オーロラがかかる

## 絵の内容は決めていません

**構図・建物・何が育つか・どんな色か——これらは指定しません。**

以前はここに「Lv1は望遠鏡と焚火、Lv2はテントとランタン……」といった細かい指定を書いていましたが、**それを読むと誰が描いても同じ絵になってしまう**ため、意図的にやめました。自由に描いてください。

ただし、**アプリの表示が壊れないための決まりごと**（何枚必要か、サイズ、ファイル名の付け方など）はあります。そちらは必ず守る必要があるので、絵に取りかかる前に必ず読んでください。

→ **[必要素材一覧](../必要素材一覧.md) の「A. 素材の規格」**

守ってほしいことの中で、特に間違えやすいのは次の3つです。

1. **1つの街につき25枚**必要です（朝・昼・夕方・夜・深夜の5パターン × Lv1〜5）
2. **25枚すべて、同じサイズ・同じ構図**にしてください
3. **雨や雪は背景に描かないでください**（アプリが上から重ねます）

理由も含めて [必要素材一覧](../必要素材一覧.md) に書いてあります。

## 街に住む人（NPC）

各街には**2人の住人**がいて、ユーザーはどちらかを選びます。選んだ住人が、勉強の前後にひとこと話しかけてくれます。

**立ち絵などの画像は作りません。**住人は文章だけで表現します。セリフはすべて [NPCセリフ集](../NPCセリフ集.md) にあります（1人あたり118本）。

## 開発者向けのメモ

- 街の英字名 `nightTown` / `castleTown` / `starHill` / `snowTown` は、DBの `town.code`・アセットのディレクトリ名・`src/constants/townArt.ts` のキーを兼ねる。**変更するとコードとデータの両方に波及する**
- `starHill` だけ `〜Town` で揃えていないのは、「ここは街ではない特別な場所」を型でも示すため
- レベル不可逆の根拠は要件6.1。住人が街に属することと選択の保持は要件7.1・設定10.12
- 仕様の正は [要件定義書](../要件定義書.md)／[ユースケース設計書](../ユースケース設計書.md)／[テーブル定義書](../テーブル定義書.md)
