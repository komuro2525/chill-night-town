# NPCセリフ集

住人（NPC）が話す**すべての文面の正**。ここを直し、`npm run npc:seed` を実行すると `db/seed_npc.sql` が生成され、アプリのDBへ入る（要件7.1）。SQLは生成物なので直接編集しない。

声色の書き分けは、並べて読み比べながら整えていく作業のため、一次資料をこのドキュメントに置いている。

## 書き方のルール

- **住人は街ごとに1人**。`## 名前` から次の `##` までが1人分。
- `- **id**:` はDBの `npc.id`。**一度使ったidは、その住人が退去しても再利用しない**（過去のセッションが指しているため）。
- `- **街**:` は `town.code`。この街を選んでいる間、この住人が話す。
- **紹介文**は `>` の引用ブロック。改行はそのままDBへ入る（設定「夜の住人」で表示）。
- 表の `感情` 列は、学習成果記録で選ばれた感情（要件3.4）。`—` は**感情を問わない候補**で、感情未選択・感情記録OFF・その感情の候補が無いときに使われる受け皿。ここが空だとその住人は何も話せなくなるため、必ず数本置く。
- **このファイルに載っていない住人はDBから削除される**（生成SQLが退去まで面倒を見る）。
- メッセージに `|` は使わない（表が壊れるため）。

## 全員に共通する基調

**責めない・急かさない・声を張らない。** 違うのは声色と比喩の引き出しだけで、厳しい住人・煽る住人は作らない。感嘆符は多用しない。目標に届かなかった夜、手応えの無い夜こそ、その事実を否定せずに受け止める言葉を置く。

各住人の人物像と街との接続は [街デザイン](街デザイン/README.md) の「住人」節にある。
