# 未使用の素材

いただいた素材のうち、現時点でアプリに組み込んでいないものを置いている。
**捨てたわけではない**ので、方針が変わったら `assets/home/weather/` などへ戻す。

## 天気演出（`天気演出/`）

天気1種につき複数パターンを持てる（どれを流すかは学習日ごとに決まる。
`src/lib/video-variant.ts`）ため、本数を増やすほど夜の表情は豊かになる。
一方で動画はそのままアプリの容量になるため、**1本あたり5MB前後**を目安に選んだ。

| ファイル | 見送った理由 |
| :--- | :--- |
| `雨_弱い1.mp4` | 24.5MB と突出して重い。加えて mvhd に尺が入っておらず（fragmented MP4 の疑い）、端末で再生できない恐れがある |
| `雨_斜め強い3.mp4` | 15.9MB。同じ「斜めの強い雨」が 4.9MB で3本あり、容量に見合う違いがない |
| `雪3.mp4` | 7.5MB。採用した雪3本と印象が近い |
| `雪5.mp4` | 6.8MB。同上 |
| `雪6.mp4` | 11.5MB。同上 |

## 環境音（`環境音/`）

環境音は単一のプレイヤーで**ループし続ける**（`src/contexts/AudioContext.tsx` の
`applyAmbient`）。そのため素材は「継ぎ目なく流し続けられる長さ」であることが前提で、
数秒の単発音は使えない。またアプリに同梱するのは mp3 のみとし、同じ内容の wav は
原本として `wav原本/` に保管している（mp3 は同じ内容で容量が約1/10）。

| ファイル | 見送った理由 |
| :--- | :--- |
| `単発の雷/`（mp3・wav 各4本） | 6〜18秒の単発の雷。ループさせると短い間隔で鳴り続けてしまう。嵐の夜には1分ものの「雷と雨」を採用した |
| `風_11秒.mp3` / `.wav` | 11秒しかなくループに向かない。夜風は3分ものを採用 |
| `強い雨.wav` | mp3 版が無く 25.7MB。嵐の夜は「雷と雨」で埋まるため出番が無い |
| `雨_室内1.wav` / `雨_室内2.wav` | 「室内で聞く雨」に対応する天気コードが無い（`night_weather` は11種）。各21MB |
| `雷と雨_別テイク.mp3` / `.wav` | 採用したものとほぼ同じ内容の別テイク。環境音は天気1種につき1つで、同じ音を2本持つ意味がない |
| `弱い雨.mp3` | 一度は「雨音の夜」に採用したが、**名前に反して実際に聴くと音が強く**、静かな雨の夜の印象に合わなかった（2026-09-08 ユーザー判断）。より小さめの素材へ差し替え、こちらを退避した。嵐の夜は「雷と雨」で埋まっているため出番が無い |
| `wav原本/` | 採用した4種（雨・雷と雨・夜風・虫）の wav 原本。アプリには mp3 を入れているため未使用だが、作り直すときの元として残す。**`弱い雨.wav` は上記の理由で現在アプリでは使っていない** |
